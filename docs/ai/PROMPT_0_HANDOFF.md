# Prompt 0 — handoff

Aktywne zadanie dla Cursora znajduje się w `docs/ai/CHATGPT_TO_CURSOR.md`.

## Uruchomienie

1. Otwórz repozytorium V2 w Cursorze.
2. Pobierz aktualny `main`.
3. Napisz do agenta: `Przeczytaj AGENTS.md i wszystkie dokumenty wskazane w aktywnym zadaniu. Wykonaj P0-BOOTSTRAP-001 dokładnie według docs/ai/CHATGPT_TO_CURSOR.md.`
4. Cursor ma utworzyć branch `cursor/p0-foundation-bootstrap`, wykonać zadanie, zaktualizować raport i otworzyć Pull Request.
5. Cursor nie może scalić PR ani rozpocząć kolejnego etapu.
