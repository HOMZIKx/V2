# DESTILED — checklist ręcznych testów (first-slice)

Cel: przejść ścieżkę bez wkłócania się. Dane lokalne w przeglądarce.

## Start

1. Otwórz web (lokalnie `pnpm --filter @v2/web dev` → `http://127.0.0.1:3000`).
2. **Kontynuuj z Discord** (symulator).
3. **Wczytaj przykładowe Asteria (demo)** albo utwórz własną przestrzeń.
4. Jeśli sesja jest brudna: **Wyczyść sesję lokalną** (pulpit / entry).
