# Grafiki map DESTILED

Do tego katalogu należy skopiować zatwierdzone pliki map ze starej aplikacji
`dobry-temat/frontend/public` pod zachowaniem nazw, np. `map_m1.png` i
`map_orki.png`.

Aplikacja korzysta wyłącznie z tego lokalnego katalogu. Nie pobiera grafik z
prywatnego repozytorium w przeglądarce produkcyjnej.
